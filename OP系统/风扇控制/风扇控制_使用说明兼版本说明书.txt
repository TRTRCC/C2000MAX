风扇控制 使用说明兼版本说明书
================================

项目名称：风扇控制
适用目录：C2000MAX / OP系统 / 风扇控制
当前版本：1.0.0
作者：搞点薯条0007


一、功能简介
------------
本插件用于 OpenWrt / LuCI 环境下的 CPU 风扇控制，提供可视化 LuCI 后台页面。

主要功能：
1. 在 LuCI 后台“服务”菜单中显示“风扇控制”页面。
2. 支持静音模式、均衡模式、性能模式、自定义模式。
3. 支持手动设置风扇占空比。
4. 支持温度-转速曲线查看、拖拽调整和保存。
5. 支持实时查看 CPU 温度、风扇占空比、WiFi 温度、5G 模组温度和风扇开关状态。
6. 启用本插件风扇控制时，会关闭原厂 fancontrol，避免控制逻辑冲突。
7. 关闭本插件风扇控制时，同步停止插件对原厂 fancontrol 的巡检关闭逻辑。
8. 右侧状态区域每 5 秒刷新一次实际温度和风扇状态。
9. 风扇动画会随实际占空比变化，转速为 0 时停止旋转。


二、安装方法
------------
推荐安装包：
风扇控制_1.0.0.ipk

兼容安装包：
luci-app-fanctrl_1.0.0.ipk

两者内容相同，区别只是文件名。OpenWrt 内部包名仍为 luci-app-fanctrl。

将 IPK 上传到路由器 /tmp 后执行：

opkg install /tmp/风扇控制_1.0.0.ipk

如果设备或终端对中文文件名支持不好，可使用：

opkg install /tmp/luci-app-fanctrl_1.0.0.ipk

如果已经安装过同版本，需要强制重装：

opkg install --force-reinstall /tmp/luci-app-fanctrl_1.0.0.ipk


三、安装后刷新 LuCI
------------------
安装完成后建议执行：

/usr/sbin/fanctrl-refresh-luci

然后在浏览器中强制刷新 LuCI 页面。

访问路径：

LuCI 后台 -> 服务 -> 风扇控制

也可以直接访问：

http://路由器IP/cgi-bin/luci/admin/services/fanctrl


四、界面使用说明
----------------
左侧区域：
1. 点击静音模式、均衡模式、性能模式、自定义模式会立即生效。
2. 手动控制区可以调整风扇占空比，松开滑块后会切换到手动模式并应用。
3. 恢复默认设置会将手动占空比恢复到 50%。

中间区域：
1. 显示 CPU 风扇动画。
2. 风扇颜色会随当前模式变化。
3. 风扇转速会随实际占空比变化，占空比为 0 时停止旋转。
4. 底部显示 CPU 温度、风扇占空比、当前模式。

右侧区域：
1. 实时状态每 5 秒刷新一次。
2. 风扇开关按钮用于控制风扇开关状态。
3. 温度-转速曲线显示当前预设策略。
4. 曲线节点可以拖拽调整。
5. 点击“保存当前曲线”后保存当前曲线配置。

底部区域：
1. “启用风扇控制”打开时，本插件接管风扇控制。
2. “启用风扇控制”关闭时，本插件停止风扇控制，并同步停止对原厂 fancontrol 的 12 秒巡检关闭逻辑。


五、模式说明
------------
静音模式：
低噪运行，优先安静，风扇响应较温和。

均衡模式：
噪声与温度自动平衡，适合日常使用。

性能模式：
优先散热，风扇响应更积极。

自定义模式：
使用用户自定义温度-转速曲线。

手动模式：
通过左侧滑块直接指定风扇占空比。


六、版本说明
------------
版本：1.0.0

本版本说明：
1. 以最新界面和风扇动画修改为基础，统一定版为 1.0.0。
2. LuCI 显示名称为“风扇控制”。
3. 包文件名不再带 -1_all 后缀。
4. 新增真实风扇风格的 9 扇叶 SVG 动画。
5. 保留按模式切换主题颜色、曲线颜色、风扇颜色的界面效果。
6. 保留温度-转速曲线读取真实配置的逻辑，不使用空曲线默认兜底伪修复。
7. 保留“点击模式立即生效”的交互。
8. 保留 5 秒实时状态刷新。
9. 修正“启用风扇控制”关闭时仍持续巡检关闭原厂 fancontrol 的问题。


七、卸载方法
------------
执行：

opkg remove luci-app-fanctrl

卸载脚本会停止并禁用本插件服务。


八、注意事项
------------
1. 如果 LuCI 页面安装后没有立即出现，请执行 /usr/sbin/fanctrl-refresh-luci 并强制刷新浏览器。
2. 如果曲线为空，不应通过前端伪造默认曲线，应检查 /etc/config/fanctrl 和 fanctrl.get_config 返回值。
3. 不建议同时运行原厂 fancontrol 和本插件控制逻辑，避免风扇策略冲突。
4. 安装包内部包名为 luci-app-fanctrl，这是为了兼容 OpenWrt / opkg 的包名规范。
